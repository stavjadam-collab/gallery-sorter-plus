# מסדר הגלריה פלוס

**אלפי תמונות וסרטונים בטלפון, ואף פעם לא מוצאים כלום?** סקיל ל-Claude Code שעובר על כל תמונה וכל סרטון, מבין מה יש בהם, מזהה מי מופיע, מפריד תמונות שנוצרו ב-AI, מוצא כפולות ומטושטשות, ומסדר הכול בתיקיות. בסוף מקבלים גם דף חיפוש: כותבים "קבלה", "חוף" או שם של אדם, והתמונות מופיעות.

הוא לא מוחק ולא מזיז שום דבר. רק מעתיק.

מבוסס על [מסדר הגלריה](https://github.com/Brain-ai-biz/gallery-sorter) של עדן ביבס / Brain (רישיון MIT). הגרסה הזו שופרה ונבנתה מחדש בחלקים על ידי [Masterphub](https://masterphub.io).

## התקנה

1. צריך [Claude Code](https://claude.com/claude-code) מותקן במחשב.
2. פותחים אותו ומדביקים:

> התקן לי את הסקיל "מסדר הגלריה פלוס" מהכתובת https://github.com/stavjadam-collab/gallery-sorter-plus : הורד את הריפו לתיקיית הסקילים שלך, ~/.claude/skills/gallery-sorter-plus (אם אין git במחשב, הורד את קובץ ה-zip של הריפו וחלץ אותו לשם). אחר כך הפעל את הסקיל, תסביר לי מה אתה עושה, ותוביל אותי צעד אחרי צעד לסדר את הגלריה שלי. דבר איתי בעברית.

3. מכאן Claude מוביל: מוצא איפה התמונות, מכין את הסביבה, מבקש מפתח של Gemini, שואל על אלבומים ואנשים, ומריץ קודם ניסיון על 200 פריטים.

## עובד אצל כולם

אייפון ואנדרואיד, מק ווינדוס:

| יש לך | מה עושים |
|---|---|
| אייפון + מק עם תמונות iCloud | כלום. הסקיל קורא ישר מאפליקציית Photos |
| אייפון + ווינדוס | iCloud for Windows מוריד את התמונות לתיקייה, או העתקה בכבל |
| Google Photos (אנדרואיד או כל אחד) | [takeout.google.com](https://takeout.google.com) ← רק Google Photos ← מורידים את קובצי ה-zip. **לא צריך לחלץ** |
| אנדרואיד בכבל | מעתיקים את התיקייה DCIM/Camera למחשב |

**עלות:** הסקיל חינם. הזיהוי ב-Gemini עולה בערך חצי דולר לאלף פריטים בחשבון בתשלום. עם זיהוי אנשים, קצת יותר, כי דף ההיכרות נשלח עם כל מנה.

**פרטיות:** רק עותק מוקטן (384 פיקסלים) נשלח לזיהוי. בזיהוי אנשים נשלחות גם תמונות ההיכרות. במסלול החינמי של Gemini, Google רשאית להשתמש בנתונים לשיפור המוצרים שלה, ובחשבון בתשלום לא. לגלריה עם ילדים, מסמכים או אנשים, עדיף חשבון בתשלום.
